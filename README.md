# 双目相机标定生产工具 (stereo-calibration)

基于已采集的同步双目图像对(data/train 188 组、data/test 15 组,cam1.jpg/cam2.jpg)计算可靠的双目相机标定结果。四个独立模块:数据预处理(角点检测与筛选)、单相机内参标定与体检、双目外参标定与验证、测量精度验证(系统漂移体检)。

```bash
uv run stereo-calib preprocess   # 模块1:角点检测
uv run stereo-calib intrinsic    # 模块2:内参 + 模型充分性体检(fail-closed)
uv run stereo-calib stereo       # 模块3:双目外参 + SC1-4 验收
uv run stereo-calib validate     # 模块4:测量精度验证(漂移体检,消费冻结产物)
```

## 支持的畸变模型布局(`intrinsic.distortion_model`)

三个布局共用同一处数学实现(`stereo_calib/intrinsic/models.py`),参数长度与
布局一一对应(4/5/8、8/9/12 互不重叠),任何代码都不许按位置猜参数。

| 模型 | params | D | 成像规则(白话) | 求解路线 | 现状 |
|---|---|---|---|---|---|
| M2 | 9 | 5 | 针孔:先取 X/Z、Y/Z,再把它弄弯 | `calibrateCamera`(无 RATIONAL) | legacy,本相机欠拟合 |
| M8 | 12 | 8 | 针孔:同上,畸变换成「分子/分母」有理式 | `calibrateCameraExtended`(CALIB_RATIONAL_MODEL)+ 洗盆 | **当前生产默认** |
| M4 | 8 | 4 | 鱼眼等距:先把入射角 θ=arctan2(r,z) 弯成 θd,像素半径 = f·θd | `cv2.fisheye.calibrate` + 多起步择优 | 2026-10-26 增补,可选 |

要点与边界:

- M4 的 D 是 `[k1,k2,k3,k4]`(θ 多项式系数),与针孔族 D 的 `[k1,k2,p1,p2,k3…]`
  **同长不同义**——四个长度互不相同(4/5/8),但语义必须凭 `distortion_model`
  自述字段解读,装载层/application 层都对错位 **中文报错不静默**。
- M4 不断言 Z>0(θ 对任意 z 符号有定义,>90° 视场也能建模);针孔族那条数据
  防线照旧保留。
- M4 的初值走**多起步**(自家 tanθ 拟合种子 + 若干典型视场的焦距猜值 + 必要时
  用本工程自己算出的针孔解换算成的量身种子),择优一律用自家 float64 回代
  RMS;单次起步失败不中断,只有全部候选都失败才报错。工程自包含,不读任何
  外部标定结果。
- M4 下 A4 探针语义退化为「同阶 cv2 鱼眼独立重标一致性」(OpenCV 没有更高阶
  鱼眼模型可升),其余 A0/A1/A2/A3 语义不变。
- **联合 BA(`stereo.joint`)对 M8/M4 一律 fail-closed**(θ 的 D 块按 M2 五参定死,
  其他布局会被静默截断);该开关当前也被 `run_stereo` 硬拦,默认 false。

## 结果溯源性

- 内参求解:solve_opencv(fresh RATIONAL)→ scipy 精化 → 第二遍 cv2 拟合洗盆(防 rational
  fx–D 简并谷)→ 体检电池(A0/A1/A3/A4 任两红即 fail-closed)
- 双目求解:逐对 PnP 相对位姿 → 剔除循环(multiplier=5,本批零剔除)→ scipy 精化
  (公共 R/T + 固定内参)→ DLT 三角测量评估
- M4 路线:`cv2.fisheye.calibrate` 多起步 → scipy 精化 → 体检(A4 改用同阶鱼眼
  重标探针)→ 逐帧 PnP 走自家精确反投影 + 切平面坐标 → 外参链路与 M2/M8 同一套
- 复现:按文首三条命令依序运行;任何一次重跑后,若结果成为新的定稿,须更新本节备份。
