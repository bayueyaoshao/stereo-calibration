# Phase 3 人工核验项(03-HUMAN-UAT)

> 背景:Phase 3 代码全链交付(214 测试绿),但真实数据生产验收 SC3 诚实 FAIL(test 距离残差 16.93mm ≫ 5mm 闸门),根因为采集物理问题(支架非刚性/同步质量),非实现缺陷。以下 4 项需人工核验/决策。

## HUMAN-1:output/stereo/ 失败留痕抽查

- **核验什么:** `output/stereo/report.md` 为正式配置(median_spread_max_deg=1.0)重跑的诚实失败留痕——中文散布防线报错(初值离散度 12.1560° > 1.0°),仅 report.md 一件、无 JSON。
- **怎么核验:** 打开 report.md 确认留痕形态;如需复现,`uv run stereo-calib stereo` 应退出码 0 并得到同数值报错。
- **判定:** 留痕如实、无带病报告 = PASS。

## HUMAN-2:联合 BA 三变体裁决数值表复核

- **核验什么:** 03-05 收敛裁决「三变体全灭」的数值是否可信:full_prior 收敛且 SC3 预演 1.53mm(达标)但内参漂移 fx +10.5%/+7.7% 越诊断界被正确拦下;裁决判据(收敛→漂移界→SC3)执行无误。
- **怎么核验:** 读 `.planning/phases/03-3/03-05-SUMMARY.md` 数值表;原始数值留档 `/tmp/joint_trial_0305_result.md`(若 /tmp 已清,重跑裁决脚本成本约 30 分钟,可向助手索取)。
- **判定:** 认可「漂移越界即灭」判据 = PASS(该判据防止用非物理参数换指标达标)。

## HUMAN-3:内参可辨识性诊断复核(关键决策依据)

- **核验什么:** 本晨诊断结论「Phase 2 内参被数据强钉死,联合 BA 漂移为 12σ–156σ 非物理解」——这是方向决策的定夺数字。
- **怎么核验:** `uv run python /tmp/ident_diag_0326.py`(只读仓库,约 5-10 分钟)复算 profile likelihood;或抽查脚本中协方差/profile 构造逻辑。
- **判定:** σ(fx)/fx ≈ 0.3–0.9% 复现 = PASS → 确认问题在内参之外(采集物理)。
